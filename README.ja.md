# NMS Save Version Tool

[English](README.md) | 日本語

No Man's Sky（PC版）のセーブデータに記録されている**バージョン番号を書き換える** Windows 用 GUI ツールです。
新しいビルドで一度遊ぶとセーブのバージョンが上がり、古いビルド（ベータ版の切り替えやロールバック後など）で読み込めなくなることがあります。このツールでバージョン番号を戻すと、古いビルドで再び読み込めるようにできます。

- 追加インストール不要（Windows 10/11 標準の PowerShell 5.1 と .NET Framework だけで動作）
- 日本語 / 英語 UI（Windows の表示言語で自動切替）
- 変更前にセーブフォルダ全体を自動バックアップ

> **注意**: 非公式ツールです。Hello Games とは関係ありません。セーブデータの改変は自己責任で行ってください。
> バージョン番号を変えても、新しいビルドで追加されたデータが古いビルドで正しく扱われる保証はありません。

## 使い方

1. 右上の **Code → Download ZIP** でダウンロードし、好きな場所に展開します。
2. （初回のみ・任意）`Create Desktop Shortcut.vbs` をダブルクリックすると、デスクトップにショートカットができます。
3. **No Man's Sky を終了してから**、ショートカット（または `NMSVersionTool.vbs`）をダブルクリックします。
4. セーブフォルダが自動で選ばれ、各セーブの現在のバージョンが表示されます。
5. 「変更後のバージョン」に目的の番号を入れ、変更したいセーブにチェックを入れて **「バックアップして変更」** を押します。
6. Steam クラウドの競合ダイアログが出たら「ローカル」を選んでください。

バックアップは `%USERPROFILE%\NMS_backup_<日時>` に作られます。元に戻すときは、その中身をセーブフォルダに上書きコピーしてください。

### ダブルクリックしても起動しないとき

ZIP から展開したファイルは Windows にブロックされることがあります。展開前の ZIP ファイルを右クリック →「プロパティ」→「許可する（ブロックの解除）」にチェックしてから展開し直してください。

セキュリティ設定で `.vbs` の実行が禁止されている場合は、展開したフォルダで次のコマンドを実行すると起動できます。

```
powershell -NoProfile -ExecutionPolicy Bypass -STA -File NMSVersionTool.ps1
```

PowerShell の言語モードが制限されている環境（会社の管理 PC など）では動作しません。

## 対応状況

| 項目 | 状況 |
|---|---|
| Steam 版（`%APPDATA%\HelloGames\NMS\st_<ID>`） | 動作確認済み |
| GOG 版（`DefaultUser` フォルダ） | フォルダは検出するが未確認 |
| Xbox / Game Pass 版 | 非対応（セーブ形式が異なる） |
| ゲームモード | ノーマルで確認。他のモードも番号は扱えるが未確認 |

**できないこと**
- 桁数が変わる変更（例: 9999 → 10000）
- 検証済みと異なる形式のメタファイル（432 バイト以外）。この場合は何も書き換えずにエラーを表示します。

## しくみ

- `save*.hg` は LZ4 ブロック圧縮された JSON で、先頭が `{"F2P":<値>,` です。`F2P` = 基本バージョン + ゲームモード × 512。
- `mf_save*.hg` は XXTEA で暗号化されたメタデータで、基本バージョンとゲームモードを含みます。
- ツールは、圧縮データ先頭の非圧縮部分にある `F2P` の数字（同じ桁数）と、メタデータの基本バージョンだけを書き換えます。ファイルサイズは変わりません。
- 書き込む前に展開して「その数字以外は1バイトも変わっていない」ことを検証し、両方のファイルを一時ファイル経由で置き換えます。メタ側の置き換えに失敗した場合は、セーブ本体を元に戻します。
- 画面に表示する「バージョン」は基本バージョンです（例: `F2P` 4738 のノーマルモードは 4226）。
